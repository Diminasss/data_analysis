# Лабораторная работа №2. Исследовательский анализ данных

Цель работы — исследовать связи между признаками набора данных о пользовательских сессиях и представить найденные закономерности с помощью таблиц и графиков.

## Материалы

| Файл | Назначение |
|---|---|
| [`ЛР2_Никитин_9.ipynb`](./ЛР2_Никитин_9.ipynb) | Ноутбук с анализом и визуализациями |
| [`visits2.csv`](./visits2.csv) | Исходные данные о сессиях пользователей |
| [`Лаб2_отчёт.pdf`](./Лаб2_отчёт.pdf) | Отчёт по лабораторной работе |

## Данные

Датасет описывает сессии пользователей интернет-магазина. Он включает идентификатор пользователя, регион, устройство, рекламный канал, даты начала и окончания сессии, продолжительность, количество кликов и товаров в корзине, стоимость покупок и возраст пользователя.

## Выполненные задачи

1. Загружены и очищены данные: обработаны пропуски и дубликаты, скорректированы типы столбцов.
2. Построены диаграммы распределения пользователей по регионам, каналам и устройствам.
3. Сформирована сводная таблица количества уникальных пользователей по рекламным каналам.
4. Построены диаграммы рассеяния и исследованы зависимости числовых признаков.
5. Рассчитаны ковариация и коэффициенты корреляции.
6. Построена тепловая карта корреляций.

## Основные результаты

- Основная часть трафика поступает из США.
- Самый распространённый рекламный канал — `organic`, наименее распространённый — `MediaTornado`.
- iPhone является самым популярным устройством и используется примерно в 43,2% сессий.
- Между количеством кликов, числом товаров в корзине и стоимостью покупок наблюдается положительная связь.

Все графики доступны непосредственно в ноутбуке и PDF-отчёте.

## Запуск

Откройте [`ЛР2_Никитин_9.ipynb`](./ЛР2_Никитин_9.ipynb) в Jupyter Notebook или [Google Colab](https://colab.research.google.com/drive/1CEWCUD_6xYkqBDXDt5RdYSi464Y2wbyH?usp=sharing), затем выполните ячейки по порядку. Файл `visits2.csv` должен находиться рядом с ноутбуком.

Используемые библиотеки: `pandas`, `matplotlib`, `seaborn`.
