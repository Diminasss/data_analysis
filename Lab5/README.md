# Лабораторная работа №5. Классификация

Работа посвящена сравнению четырёх методов бинарной классификации для прогнозирования летального исхода у пациентов с сердечной недостаточностью.

## Постановка задачи

Целевая переменная `DEATH_EVENT` показывает, наступил ли летальный исход в период наблюдения. В качестве признаков используются возраст и медицинские показатели пациента, сведения об анемии, гипертонии, диабете, курении и другие параметры.

## Выполненные задачи

1. Проверено наличие пропусков и дубликатов — в исходном наборе они не обнаружены.
2. Построена матрица диаграмм рассеяния с окраской по целевому классу.
3. Данные разделены на обучающую и тестовую выборки в пропорции 3:1; числовые признаки стандартизированы.
4. Обучены KNN, дерево решений, логистическая регрессия и случайный лес.
5. Рассчитаны Accuracy, Precision, Recall, Balanced Accuracy, F1 и специфичность.
6. Для каждой модели построена матрица ошибок, модели сопоставлены по ROC-кривым и AUC.
7. Исследовано влияние `max_depth` на качество дерева решений; оптимальной для тестовой выборки оказалась глубина 3.

## Основные результаты

- Случайный лес показал Accuracy 0,84, Precision 0,89, Recall 0,63, F1 0,74 и Balanced Accuracy 0,79.
- Лучшее значение AUC у случайного леса — 0,934; у KNN — 0,872, у логистической регрессии — 0,848.
- Ограничение глубины дерева до трёх уровней улучшило его способность обобщать данные и снизило переобучение.
- Классы частично пересекаются, поэтому качество моделей зависит от выбранной метрики и цены ошибок разных типов.
